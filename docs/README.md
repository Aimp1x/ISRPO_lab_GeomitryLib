# Project description
**GeometryLib** - это простая библиотека на Python. Она позваляет расчитать площадь и периметр двух базовых фигур: круга и квадрата.

# Functionality
## circle.py
### area(r)
> Принимает радиус (float)r и возращает площадь круга типа (float)

**Example**
```Python
print(area(5)) # Посчитает площадь круга с радиусом 5
```

### perimeter(r)
> Принимает радиус (float)r и возращает периметр круга типа (float)
    
**Example**
```Python
print(perimeter(5)) # Посчитает периметр круга с радиусом 5
```

## square.py
### area(a) 
> Принимает сторону (float)a и возращает площадь квадрата типа (float)

**Example**
```Python
print(area(5)) # Посчитает площадь квадрата со стороной 5
```

### perimeter(a)
> Принимает сторону (float)a и возращает периметр квадрата типа (float)

**Example**
```Python
print(perimeter(5)) # Посчитает периметр квадрата со стороной 5
```
